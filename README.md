# Equilibra

App web per allenamento, coach AI, dieta settimanale e lista della spesa condivisa.
Dati salvati sul dispositivo; AI tramite chiave personale gratuita di Google Gemini; famiglia (spesa condivisa) tramite Firebase.

Crediti: esercizi e immagini free-exercise-db (Unlicense); valori nutrizionali USDA FoodData Central SR Legacy (pubblico dominio) tramite il dataset TempoLife (CC-BY-4.0); Firebase JS SDK (Apache-2.0).
